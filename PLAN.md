## 5. Design System — Mobile-First

- **Approach:** Design at 360px first, then scale up to 768px, 1024px. No desktop-only features.
- **Palette (luxury heritage, high contrast):** Deep maroon `#5C0E1B` (primary), antique gold `#C9A227` (accent), ivory `#FFF9F0` (bg), charcoal `#1F1B16` (text), emerald touch `#0E4D3C` for details, WhatsApp green `#25D366` only for action buttons. WCAG AA contrast. Generous whitespace, thin gold dividers, craft-feel.
- **Type:** System stack only (no webfont delay): `system-ui, -apple-system, "Noto Sans", "Nirmala UI", sans-serif`. H1 32px mobile / 56px desktop, body 16-17px, line-height 1.6.
- **Layout:** Single column mobile, max-width 1120px, 16px padding, cards stack vertically. Sticky header 56px, sticky bottom call-bar (Call | WhatsApp | Directions) on <768px only.
- **Images:** 16:9 hero, 4:5 for saree portraits, `loading="lazy"` except hero, `width/height` set to avoid CLS, WebP with JPEG fallback, compressed <150KB each.
- **Interactions:** Hamburger menu, smooth scroll, FAQ accordion (<details>), ROI slider (vanilla JS), back-to-top, no heavy libraries. Total JS <20KB.
- **Accessibility:** Semantic landmarks, focus states, alt text, tel links, colour not sole signal.

Wireframe (text): Header[Logo|Call btn|Menu] → Hero[Headline|2 CTAs|hero image|rating chips] → Categories[2-col grid mobile] → Skills[stacked cards] → … → Contact[big buttons] → Footer.
